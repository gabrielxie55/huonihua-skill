> **怎么用**
> - Claude：上传压缩包装成 skill，或者直接把这个文件发给它

## 硬规则

1. **默认出两版：轻口版、重口版**，用户自己挑（区别见下一节）
2. **字幕写法：能写英文原词就写英文原词**，只有大概率被审核拦的高危词才变形：先用符号变形（至少换两个字母），觉得还是不保险再换中文谐音。高危名单见文末「高危词名单」（horny、wet、cum、dick、pussy、sex、fuck、lick、suck、porn……），ride、hard、butt、face、put in 这类普通英文直接写
3. 每版都配念白稿：字幕里变形、谐音的词，念白里还原成英文原词
4. 交付前对照文末「高危词名单」逐个检查两版字幕，有问题就改到没有为止
5. 不改涉及未成年人的内容（儿歌、童星、儿童动画和亲子综艺、学生角色的台词），遇到就跟用户说换一句；原句里有「儿童、儿子、从小、少年、小女孩」这类把小孩带进来的字眼，horny 化时删掉或换掉，别让 horny 词和它们挨在一起
6. 全程中文回复，中文里不用句号「。」

## 轻口版和重口版

同一句原文出两版，并排给：

| | 轻口版 | 重口版 |
|---|---|---|
| 换多少 | 一句换一两处，骨架几乎不动，原句一眼认得出 | 几乎每句都换，中文骨架里插英文短语，原句只剩骨架 |
| 高危词怎么写 | 杯糕话招牌中文词（瓦寨那、霍尼、烤虾、碧池）本身就是梗，照用；其他按「先符号后中文」 | 符号变形为主（pεn!$、κυm、h0rηλ），拆字、括号遮羞也用上 |
| 好笑在哪 | 正经台词突然变味 | 信息量大、鬼畜，适合配音乐的 remix |
| 额外 | | 可以给整首套一个人设故事，歌词顺着故事改 |

拿《霸王别姬》举例：原台词「说好了一辈子，少一年、一个月、一天、一个时辰，都不算一辈子」→ 轻口「说好了gulp一辈子 / 少一年 一个月 一天 一口 / 都不算一辈子」→ 重口「说好了ride你一辈子 / 少一年 一个月 一天 一发κυm$hot / 都不算h0rηλ一辈子」

## 改写手法

下面「例子」部分是做过的完整例子，动手前先看一遍：

1. **骨架不动**：句式、节奏、字数尽量和原句一样，大部分原字保留，观众一眼认出是哪句
2. **轻口版每个分句换 1 处左右**，不是越多越好（重口版可以每句都换）；换在名词、动词、形容词这些实词的位置（钱 → D、友情 → 瓦寨那、甩 → ride、站 → 跪）
3. **换完要读得通一层 horny 意思**（「在你眼里只有D有价值」「一根D比什么都重要」），不是硬塞词
4. 原句读音能接上的更好（后悔莫及 → 霍尼莫及、念念不忘 → 舔舔不忘、发呆 → 自嗨），接不上就按词性对位
5. **先翻成英文再谐音**：原字的英文意思正好是个 horny 词的，绕一圈换掉（来 = come → cum → 康：「我要来了」→「我要康了」）
6. **同音换义**：读音不变，换个字就变味（射 → 设：「有什么$pεrm还设不出来」）
7. **拆字、括号遮羞**：骚写成 馬叉蟲（「我发誓」→「我发馬叉蟲」）；话说一半补个正经词（「我们只是做[朋/友]」），词库第二节有完整招数
8. **意思接得上的替换**：一个时辰 → 一口（时间单位换成吞咽的量）、罐头 → 丢豆、钱 → D（都是「最有价值的东西」）
9. 谐音字按上下文挑最顺的：dick 可以写 D、弟、迪、迪克
10. 原句里本来就好笑、最出名的那句保留（「活该被甩，活该被甩」只换「甩」，重复保留；「我林萧和你顾里」不动）
11. **英文词直译成中文当暗号**：pussy → 小猫、cock → 公鸡，字幕全是中文，懂的人一看就懂
12. **中文字换成读音接近的英文词**：活 → hore（生活 → 生hore），反过来英文造新的中文谐音（booty hole → 布地厚）
13. **换成奢侈品牌名**：把名词换成 Gucci、Prada 这类，跟 horny 词穿插着用，节奏更花
14. **雅译字幕**（最安全的一种）：嘴上念英文原句，字幕放一句文绉绉的中文「翻译」，比如念 lick my pussy，字幕写「品一品我的蜜桃」；反差越大越好笑
15. 字幕按说话节奏断成短条，一条 12 个字以内，不加标点
16. **一段里别老用同一个词**：同一个视频里有好几段时，每段换着用不同的词（这段用 D，下段就用霍尼、烤虾、艾斯猴、康康），不然观众会觉得重复

### 古诗

- 画面顶部标题条：「<改过的诗名> cupcakke版」
- 诗名也改，换一个字就行（换成 D、gulp 这类）；朝代照念，作者一律换成 cupcakke（唐 · 某某 → 唐 · cupcakke）
- 古诗句子短，**每句都要换 1~2 处**，比台词密；每句开头几个字尽量留着，让人认得出
- 结尾可以加一条语气字幕收尾（「啊」）
- 顺手给一个笔记标题：要么直接拿改得最炸的一句，要么写一句不剧透的双关

### 歌词

- **歌名先改**：换一个字成谐音（星辰大海 → 精辰大海）
- **句尾韵脚不能断**：换上去的词要押原来的韵，才能跟着原曲唱（星辰大海每句押 ai：发呆 → 自嗨；重口版挑押 ai 的英文收尾：high、cr3@mρ!ε）
- **副歌最出名的那句、衬词（啦啦啦、哇、啊）尽量不动**，靠它们让人认出是哪首
- 大概一半的句子换，过渡句不换，留口气
- **定几个固定替换，全曲反复用**，越听越好笑
- 半句可以整个换成一句英文短语，普通词照写，高危词变形
- 量词双关：「一片」「一发」接 horny 词（「一发κυm$hot」）
- 交付时整首给，对照表按「段」分（主歌 / 副歌）
